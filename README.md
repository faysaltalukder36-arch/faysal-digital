# Md. Faysal Talukder — Portfolio / Personal Brand Website

A responsive, SEO-ready static portfolio rebuilt around a warm cream/navy/orange visual identity, stronger UX hierarchy, accessible navigation, recognizable social icons, premium footer and GitHub Pages compatibility.

## Deploy
1. Upload the **contents** of this folder to the repository root.
2. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
3. Replace `https://YOUR-DOMAIN.com` in all canonical/SEO files with your real domain.
4. Keep the preserved contact/social URLs unchanged unless you intentionally want to change them.
